# References & Academic Citations

This project implements the foundational principles of sequence-based log anomaly detection pioneered in the systems and deep learning literature:

1. **DeepLog: Anomaly Detection and Diagnosis from System Logs through Deep Learning**
   - Authors: Min Du, Feifei Li, Guineng Zheng, Vivek Srikumar (University of Utah)
   - Conference: Proceedings of the 2017 ACM SIGSAC Conference on Computer and Communications Security (ACM CCS '17), Dallas, TX, USA.
   - DOI: [10.1145/3133956.3134015](https://doi.org/10.1145/3133956.3134015)
   - Contribution: Re-formulated unstructured system logs as language sequences; introduced next-event top-k candidate prediction using Long Short-Term Memory (LSTM) networks.

2. **Detecting Large-Scale System Problems by Mining Console Logs**
   - Authors: Wei Xu, Ling Huang, Armando Fox, David Patterson, Michael I. Jordan (UC Berkeley)
   - Conference: Proceedings of the ACM SIGOPS 22nd Symposium on Operating Systems Principles (SOSP '09), Big Sky, MT, USA.
   - Contribution: Original HDFS log dataset collection, block-level execution session grouping, and PCA state-vector baseline.

3. **Loghub: A Large Collection of System Log Datasets towards Automated Log Analytics**
   - Authors: Shilin He, Jieming Zhu, Pinjia He, Michael R. Lyu (Chinese University of Hong Kong)
   - ArXiv: [arXiv:2008.06448](https://arxiv.org/abs/2008.06448) (2020)
   - Contribution: Standardized repository of enterprise system logs (HDFS, BGL, Hadoop, Spark, OpenStack, Linux).

4. **Kaggle: Log Data for Anomaly Detection**
   - Author: Krish Dubey (`krishd123`)
   - URL: [https://www.kaggle.com/datasets/krishd123/log-data-for-anomaly-detection/data](https://www.kaggle.com/datasets/krishd123/log-data-for-anomaly-detection/data)
   - Description: Benchmark telemetry log dataset for machine learning and deep learning anomaly detection research.
